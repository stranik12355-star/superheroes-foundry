# Супергерои — Foundry VTT

Первая рабочая версия самостоятельной системы для Foundry VTT 12.

## Структура
- `system.json` — манифест системы
- `scripts/superheroes.js` — механика и лист персонажа
- `templates/actor-sheet.hbs` — интерфейс
- `templates/roll-card.hbs` — карточки бросков
- `styles/superheroes.css` — оформление
- `lang/ru.json` — русские названия характеристик

## Базовая механика
3d6. Центральная кость отличается визуально. Если на центральной кости выпадает 1, показывается ★; это крит и при подсчёте считается как 6.

Начальные характеристики — 10. Модификатор = значение - 10.

ХП и Фокус: 10 при характеристике 10 или ниже; 30 при 11; 60 при 12; далее +30 за каждое очко.

Ранг 1–5 определяет максимум Кармы и базовый множитель атаки.
