# Супергерои — Foundry VTT

Самостоятельная система НРИ о супергероях для Foundry VTT 12.

## Структура

После распаковки архив должен создать папку:

`superheroes/`

В ней непосредственно находится `system.json`.

- `system.json` — манифест системы
- `scripts/superheroes.js` — механика и лист персонажа
- `templates/actor-sheet.hbs` — лист персонажа
- `templates/roll-card.hbs` — карточки бросков
- `styles/superheroes.css` — оформление
- `lang/ru.json` — русская локализация

## Базовая механика

- Проверки: 3d6 + модификатор характеристики.
- Все характеристики начинают с 10; модификатор равен `значение - 10`.
- Центральная кость отличается визуально. Центральная `1` превращается в `★`, считается как 6 и является критом.
- Единица на боковой кости остаётся обычной `1`.
- Под каждой из трёх костей доступны «Преимущество» и «Помеха»; выбранная кость перебрасывается отдельно.
- Ранг 1–5 задаёт максимум Кармы и базовый множитель урона.
- ХП и Фокус рассчитываются от Выносливости и Бдительности соответственно: 10 при 10 и ниже, 30 при 11, 60 при 12, далее +30.
