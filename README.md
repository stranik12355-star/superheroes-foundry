# Супергерои — Foundry VTT

Самостоятельная система НРИ о супергероях для Foundry VTT 12.

Структура архива:
- `superheroes/system.json`
- `superheroes/scripts/superheroes.js`
- `superheroes/styles/superheroes.css`
- `superheroes/templates/actor-sheet.hbs`
- `superheroes/templates/roll-card.hbs`
- `superheroes/lang/ru.json`

Основная механика:
- проверки 3d6 + модификатор характеристики;
- центральная единица превращается в ★, считается как 6 и является критом;
- боковые единицы остаются обычными 1;
- отдельное преимущество/помеха для каждой кости;
- ХП и Фокус рассчитываются от Выносливости и Бдительности;
- ранг 1–5 задаёт максимум Кармы и базовый множитель урона.
